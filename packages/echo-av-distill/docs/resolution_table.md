# Echo SR 2x Latent SR 分辨率查表

## 约束条件

- 宽和高必须被 **32** 整除（VAE 空间压缩因子）
- 帧数必须满足 `frames % 8 == 1`（时间压缩因子），常用：9, 17, 25, 33, 41, 49, 57, 65, 73, 81, 89, 97, 121
- HQ = LQ × 2（精确 2 倍）
- CondLatent2xProj 分辨率无关，以下任何组合均可直接使用同一份权重

## 2x SR 分辨率表

| LQ (WxH) | HQ (WxH) | Latent LQ | Latent HQ | HQ Tokens (T=16) | 显存估算 (bf16) |
|-----------|-----------|-----------|-----------|-------------------|-----------------|
| 512×320 | 1024×640 | 16×10 | 32×20 | 10,240 | ~15GB |
| 640×384 | 1280×768 | 20×12 | 40×24 | 15,360 | ~20GB |
| 768×448 | 1536×896 | 24×14 | 48×28 | 21,504 | ~28GB |
| 832×480 | 1664×960 | 26×15 | 52×30 | 24,960 | ~32GB |
| 960×544 | 1920×1088 | 30×17 | 60×34 | 32,640 | ~40GB |
| 960×576 | 1920×1152 | 30×18 | 60×36 | 34,560 | ~42GB |
| 1024×576 | 2048×1152 | 32×18 | 64×36 | 36,864 | ~45GB |
| 1280×736 | 2560×1472 | 40×23 | 80×46 | 58,880 | ~70GB |
| 1280×768 | 2560×1536 | 40×24 | 80×48 | 61,440 | ~73GB |
| 1920×1088 | 3840×2176 | 60×34 | 120×68 | 130,560 | ~150GB+ |

> **Tokens 计算**: T_latent × H_latent × W_latent，其中 T_latent = (frames-1)/8 + 1 = (121-1)/8+1 = 16
>
> **显存估算**: 单卡 batch=1 的近似值（含模型 + optimizer + activations），实际取决于 FSDP 分片数

## 推荐训练路线

### 阶段一：低分辨率快速收敛
```yaml
lq_resolution: [640, 384, 121]     # latent 20×12, tokens=15360
hq_resolution: [1280, 768, 121]    # latent 40×24
```
- 每步 ~20-30s（8×H200）
- 适合初期 SFT 训练到 loss 收敛

### 阶段二：中分辨率精调
```yaml
lq_resolution: [960, 576, 121]     # latent 30×18, tokens=34560
hq_resolution: [1920, 1152, 121]   # latent 60×36
```
- 每步 ~50-60s（8×H200）
- 从阶段一的 checkpoint 继续训练
- 模型学习更大分辨率下的高频细节

### 阶段三：高分辨率微调（可选）
```yaml
lq_resolution: [1280, 736, 121]    # latent 40×23, tokens=58880
hq_resolution: [2560, 1472, 121]   # latent 80×46
```
- 每步 ~90-120s（8×H200）
- 需要 batch_size=1 或 48 卡分布式
- 训练真正的 2K→4K 超分能力

## 推理时分辨率选择

由于 CondLatent2xProj 是分辨率无关的，推理时可以用在**任何**被 32 整除的分辨率上：

```python
# 训练在 640×384 → 1280×768
# 推理直接用在：
#   720p → 1440p:  1280×720 → 2560×1440 ✓
#   1080p → 2160p: 1920×1088 → 3840×2176 ✓
#   任意分辨率:     W×H → 2W×2H (W,H % 32 == 0) ✓
```

## LTX-2.3 原生支持的生成分辨率

这些是 LTX-2.3 基模能稳定生成的分辨率（作为 LQ 输入源）：

| 分辨率 (WxH) | 宽高比 | Latent | 说明 |
|---|---|---|---|
| 576×576 | 1:1 | 18×18 | 方形，最小 |
| 768×448 | ~16:9 | 24×14 | 小尺寸宽屏 |
| 960×576 | 5:3 | 30×18 | 中等宽屏 |
| 1024×576 | 16:9 | 32×18 | 标准 16:9 |
| 1280×736 | ~16:9 | 40×23 | **官方推荐分辨率** |
| 1920×1088 | ~16:9 | 60×34 | 高分辨率 |
